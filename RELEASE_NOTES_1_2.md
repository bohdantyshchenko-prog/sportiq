# NOVIQ 1.2 Release Notes

## Live Intelligence & Retention

- rebuilt Home around a Daily Intelligence Brief
- added explainable Match of the Day and Recommendation Engine V1
- added provider-aware Personal Match Center with search, dates and personalised filters
- added Dynamic AI Briefing sections for facts, signals, unknowns and changes
- added Match Thesis V2 per match with immutable local Decision Lock
- added simulated Live Intelligence timeline and separate private observations
- added Decision Replay V2 with explicit reflection and Sports IQ updates
- added Confidence Lab V2, Sports Memory V3 and Weekly Report V2
- added account/sync architecture shell without fake authentication
- added modular service adapters and safe fallback data
- added 1.0/1.1 browser-state migration, PWA cache refresh and JSON export

The public build uses a labelled static dataset and deterministic local AI. Production integrations remain separate work.
