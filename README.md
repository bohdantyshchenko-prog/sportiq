# NOVIQ / SportIQ

NOVIQ is a Sports Intelligence product built around one core loop:

**AI Briefing → Match Thesis → Decision Replay → Sports IQ → Sports Memory**

## Current build

This repository contains the first mobile-first web alpha. It opens directly in guest mode, so language selection and authentication never block testing.

## Run locally

Open `index.html` in a browser or serve the folder with any static server.

## Publish

The included GitHub Pages workflow deploys the repository automatically after every push to `main`.

## Product status

Alpha prototype. Sports data, real authentication, server-side AI, push notifications and cloud sync are still demo/local implementations until external services are connected.
