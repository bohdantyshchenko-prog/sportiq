## NOVIQ 1.4.0 — Real-Data-Ready Client

- runtime environment configuration
- resilient API client with timeout, retry and structured errors
- remote sports gateway and server AI adapters
- automatic, explicit demo fallback

- automated GitHub Actions smoke checks

### Hardened

- local-state migration from 1.0, 1.1 and 1.2
- nested state validation
- localStorage failure handling
- dynamic HTML escaping
- modal focus restoration
- invalid navigation guards
- PWA cache invalidation

### Honest limitations

NOVIQ 1.4 is integration-ready, not a deployed production backend. Real sports data, server AI, authentication, cloud sync and push notifications require credentials and infrastructure outside this repository.
