Privacy

Effective date: August 6, 2026.

Local storage

The closed-beta build stores profile settings, Match Theses, Decision Replays, Sports IQ, local diagnostics, and optional beta feedback on the current device.

No external analytics

This offline build does not send telemetry, questions, feedback, or sports decisions to an external server. Clearing browser storage or resetting NOVIQ removes local data unless the user exported a backup.

User control

Users can export, import, inspect, and delete their local progress from the Profile screen.

This page is a beta disclosure, not a substitute for jurisdiction-specific legal review before a public commercial release.
