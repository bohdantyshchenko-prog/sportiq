Privacy

Effective date: August 13, 2026.

Local Preview

If you choose Local Preview, NOVIQ stores profile settings, Match Theses, Decision Replays, Sports IQ, local diagnostics, beta metrics, and optional feedback in browser storage on that device. These product records are not synchronized to the NOVIQ backend.

Cloud Account

If cloud login is enabled and you create or use an account, authentication is handled by Supabase Auth. NOVIQ may synchronize your email identifier, display name, locale, theme, timezone, favorite team, Sports IQ, Match Theses, Decision Replays, and derived Sports Memory to the NOVIQ API and PostgreSQL database. The current closed beta still uses curated demonstration sports data unless explicitly stated otherwise in the app.

Authentication data

NOVIQ never stores your password in product storage. The browser keeps the authentication session required to remain signed in. Authentication requests are not cached by the NOVIQ service worker.

Diagnostics and feedback

Product telemetry and crash diagnostics are bounded and local-only in this build. Optional beta feedback also remains local unless you deliberately export or share a beta report. Email-like strings are redacted from local telemetry where supported.

AI and sports providers

The beta can run without external AI or sports providers. If those integrations are enabled later, the app must identify that state. Server AI requests may include the sports context or Thesis content required to answer the request; passwords and authentication tokens must not be sent to AI providers.

Your controls

You can export or reset local progress. A signed-in user can request deletion of NOVIQ cloud profile data, Thesis, Replay, Memory, and related product records from the Profile screen. This beta deletion does not delete the underlying Supabase authentication identity itself.

Security and retention

NOVIQ uses authenticated API requests, per-user ownership checks, rate limits, no-store API responses, restricted browser permissions, and transport security headers. Closed-beta data should be retained only as long as needed to operate and evaluate the beta. A public commercial launch requires a finalized retention schedule and jurisdiction-specific privacy review.

This is a closed-beta privacy disclosure and not a substitute for professional legal review before a public commercial release.
