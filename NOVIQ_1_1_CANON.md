# NOVIQ 1.1 Canon — First Intelligence Loop

## Product promise

NOVIQ does not reward lucky score guesses. It measures and develops the quality of football reasoning.

## Locked loop

1. Adaptive Sports IQ Diagnostic
2. AI Briefing with facts, signals and unknowns
3. Match Thesis V2
4. AI Thesis Review V2
5. Decision Lock
6. Decision Replay V2
7. Learning Loop
8. Sports Memory V2
9. Sports IQ update and next personal mission

## 1.1 release scope

### Adaptive Diagnostic
- 10 scenarios across Tactical, Context, Data, Decision and Learning IQ
- core and advanced difficulty
- confidence recorded for every answer
- skill-level evidence confidence

### Match Thesis V2
- Quick and Expert modes
- expected outcome and match scenario
- primary and independent secondary argument
- key player or tactical zone
- sources used
- principal risk
- alternative scenario
- evidence that would change the decision
- confidence from 40 to 95 percent
- draft version history
- immutable timestamp after lock

### AI Review V2
- specificity
- causality
- evidence breadth
- risk quality
- confidence calibration
- cognitive-bias scan
- missing context
- alternative scenario and challenge question

### Decision Replay V2
- match timeline
- confirmed and broken assumptions
- score breakdown
- foreseeable versus random factors
- confidence gap
- mandatory user reflection

### Learning and Memory
- one lesson, example and control question
- one similar match
- one personal mission
- evidence-backed memory patterns
- ability to dispute a pattern

## Explicit exclusions

Version 1.1 does not connect real sports APIs, server AI, real authentication, social graph, betting, scouting, multi-sport or payments.
