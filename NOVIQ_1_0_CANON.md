# NOVIQ 1.0 Canon

## Positioning

NOVIQ is not a live-score clone and not a betting-tip product. It is a personal sports intelligence layer that records how a user thinks, reviews decisions and builds a long-term Sports Memory.

## Core loop

1. AI Briefing
2. Match Thesis
3. AI Review
4. Decision lock
5. Match / Live Intelligence
6. Decision Replay
7. Sports IQ update
8. Sports Memory pattern
9. Personal mission
10. Weekly Intelligence

## Locked navigation

- Home
- Matches
- AI Core
- Intelligence
- Profile

## Locked Home order

1. Sports IQ identity
2. World Cup Command Center
3. AI Briefing / Match of the Day
4. Live Intelligence
5. Sports Twin
6. Future Self
7. Memory Moment
8. Geo Intelligence
9. Community Pulse
10. Today For You
11. Weekly Wrapped

## Design canon

- Dark Elite is default
- Light Elite is optional
- Black/graphite foundation
- Purple AI energy
- Gold for status and achievement
- Green only for positive or live signals
- Premium rounded cards
- Mobile-first safe-area layout
- No generic news-feed visual language

## Version 1.0 acceptance criteria

- The app opens directly without a blocking login or language screen
- Every primary visible control produces a meaningful action
- Thesis data persists locally
- Locked Thesis cannot be silently edited
- Decision Replay changes Sports IQ and Sports Memory
- Language and theme changes work immediately
- The build remains usable offline after first load
